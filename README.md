# วันละ Craft / One Per Craft

ศูนย์กลางของ Tapanapon สำหรับรู้จัก Craft Apps ครบ 16 แอป รวม GitHub ของแต่ละโครงการ เวอร์ชันต้นฉบับ รุ่นภาษาไทย คู่มือติดตั้ง Mac/Windows และการเชื่อม Codex หรือ Claude

[เว็บไซต์วันละ Craft](https://tapanapon.com/one-per-craft) · [ดาวน์โหลดต้นฉบับครบ 16 แอป](https://getartcraft.com/apps) · [Version Log](https://tapanapon.com/one-per-craft/versions) · [English](#english)

## ตอนนี้มีอะไรพร้อมแล้ว?

**แอปรุ่นภาษาไทยที่เผยแพร่แล้วมี 4 แอป:** VectorCraft TH, PhotoCraft TH, FilmCraft TH และ LightCraft TH โดยคง repository และไฟล์ Release เดิมไว้ รุ่นไทยทั้ง 4 รวม tag ต้นฉบับล่าสุดที่ตรวจ พร้อมตัวติดตั้ง Mac Apple Silicon / Windows x64 และผลตรวจแยกตามแพลตฟอร์ม

**อีก 12 repository เริ่มต้นด้วยเอกสารและ manifest อ้างอิงต้นทาง** ยังไม่มีซอร์สแอป คำแปลที่พร้อมแจก หรือไฟล์ติดตั้งภาษาไทยใน repo ใหม่เหล่านี้ การมี repository ครบไม่ใช่การประกาศว่ารุ่นไทยครบ 16 แอปแล้ว

## ทำอะไรได้บ้าง

- เลือกแอปและเปิด GitHub ของแต่ละโครงการจากตารางเดียว
- เปรียบเทียบรุ่นต้นฉบับกับรุ่นไทยที่เผยแพร่จริง
- อ่านคู่มือติดตั้ง Mac/Windows และวิธีเลือกไฟล์จาก GitHub Releases
- อ่านสรุปการเปลี่ยนแปลงภาษาไทยพร้อมเครดิตและลิงก์ต้นทาง
- เริ่มตั้งค่า CLI/MCP สำหรับ Codex หรือ Claude ตามเอกสารของแต่ละแอป

## ดาวน์โหลดและติดตั้งบน Mac

1. เลือกแอปและดูว่าต้องการรุ่นไทยที่เผยแพร่แล้วหรือต้นฉบับล่าสุด
2. เปิด Release ของรุ่นนั้น แล้วเลือก DMG ให้ตรงชิปและข้อกำหนดระบบ
3. บันทึกงานและปิดแอปเดิม เปิด DMG แล้วลากแอปเข้า Applications
4. ตรวจ SHA-256 และข้อจำกัดของแพ็กเกจก่อนเปิด

รุ่นไทย 4 แอปที่เผยแพร่ใช้ Mac Apple Silicon ส่วนต้นฉบับล่าสุดที่ตรวจมี Universal DMG [อ่านคู่มือ Mac](docs/install-macos.md)

## ดาวน์โหลดและติดตั้งบน Windows

เลือก MSI เพื่อติดตั้ง หรือ Portable ZIP แล้ว Extract All ก่อนเปิด `.exe` เลือกสถาปัตยกรรมให้ตรงเครื่อง และตรวจ checksum ของไฟล์ชนิดเดียวกันใน Release เดียวกัน [อ่านคู่มือ Windows](docs/install-windows.md)

## ใช้กับ Codex หรือ Claude

ต้องติดตั้ง CLI ของแอปและลงทะเบียน MCP ก่อน การมีตัว GUI หรือดาวน์โหลด source ZIP อย่างเดียวไม่เชื่อมกับ AI อัตโนมัติ อ่าน [คู่มือเชื่อม AI](docs/automation.md) และเอกสารต้นทางของแต่ละแอป

## บันทึกเวอร์ชันและการอัปเดต

- [Version Log รวม](docs/version-log.md): สรุปสิ่งที่เปลี่ยนในต้นฉบับและประวัติรุ่นที่ตรวจ
- [CHANGELOG ของศูนย์กลาง](CHANGELOG.md): การเปลี่ยนแปลงเอกสารและโครงสร้างชุดนี้
- [apps.json](apps.json): ข้อมูล repository, สถานะรุ่นไทย, Release ต้นฉบับ และ URL ดาวน์โหลด
- `python3 tools/check_upstream.py`: ตรวจ Release ต้นฉบับล่าสุดแบบอ่านอย่างเดียว ต้องมี GitHub CLI (`gh`) ไม่แก้ไฟล์หรือเผยแพร่อัตโนมัติ

ข้อมูลนี้เป็น snapshot ณ เวลาตรวจที่ระบุ การอัปเดตครั้งใหม่ต้องตรวจ Release/ไฟล์จริงและปรับ Log โดยไม่ใช้เลข Cargo.toml ของ branch แทนเวอร์ชันตัวติดตั้ง

## English

One Per Craft is Tapanapon's independent hub for all 16 officially listed Craft Apps: per-app repositories, verified upstream releases, published Thai editions, Mac/Windows installation guides and Codex/Claude MCP references.

### Features and workflow

Use the app table to find each project, compare upstream and Thai versions, read version notes and choose an installer from GitHub Release Assets. The central repository contains documentation, a manifest and a read-only release checker; it is not a single merged application source tree.

### Downloads and installation

Four Thai applications are already published: VectorCraft TH, PhotoCraft TH, FilmCraft TH and LightCraft TH. Their repositories/releases are retained. Twelve additional repositories are documentation-only preparation projects; they do not yet contain application source trees or Thai installers. Original upstream downloads remain clearly labeled.

### Coverage and validation

Release metadata and asset links were checked at 08/11/2026 21:15 ICT. Native runtime validation of all upstream applications is not claimed. No new Thai binary is published simply by creating these repositories. Source, release and Thai-edition versions are tracked separately.
